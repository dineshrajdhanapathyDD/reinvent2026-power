# re:Invent 2026 catalog — agent guidance

When the user asks about AWS re:Invent 2026 sessions, planning, venues, or travel,
use the `reinvent2026` MCP tools rather than guessing.

Guidance:
- For a specific topic or code, use `search_sessions`. For a described learning
  goal in the user's own words (e.g. "help me build production agents"), prefer
  `semantic_search`.
- For "how do I get from X to Y" use `estimate_travel`; distinguish walk vs.
  shuttle. re:Invent spans six venues across the Las Vegas Strip — never treat it
  as one building.
- Always link back to official AWS pages via `official_links`. Present agent
  output as a recommendation and AWS as the source of truth
  ("Re:Route AI recommends; AWS re:Invent confirms").
- Session times/venues from the bundled catalog are estimated placeholders until
  AWS publishes the schedule; say so when it matters. Do not fabricate exact
  room numbers or times.
